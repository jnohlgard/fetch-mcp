# Security Findings — Automated Test Plan

Companion to `docs/security-findings.md`. One evaluation strategy per finding, with an offline verdict. Conventions follow the existing suite: `bun:test` with jest-style mocks, `globalThis.fetch` replaced by `jest.fn()`, `dns.promises.lookup` stubbed to a public IP in `beforeEach` (restored in `afterAll`), `Fetcher.hasYtDlp` reset in `beforeEach`, `process.exit`/stdio monkeypatched in CLI tests.

**Environment assumption:** no internet, no external DNS. Loopback (`127.0.0.1`) networking *is* available — that is local, not internet — so local HTTP servers are a valid test fixture. Where a finding depends on external hosts, it is flagged and given a component-level fallback.

## Per-finding test strategy

| # | Finding (severity) | Automated evaluation | Offline? |
|---|---|---|---|
| 1 | IPv4-mapped IPv6 SSRF (Critical) | (a) Unit: normalization/checker helper rejects `::ffff:7f00:1`, `::ffff:a00:1`, and long form `::ffff:10.0.0.1` (the current code returns `false` for these — the unit test is a live repro today). (b) Integration: start a local HTTP server on 127.0.0.1; call `Fetcher.html({ url: "http://[::ffff:127.0.0.1]:<port>/" })`; assert `isError === true` **and** the server received zero requests. Both tiers pass only after the fix; (b) proves the request never leaves the host. | Yes (loopback only) |
| 2 | yt-dlp path skips all URL validation (Critical) | Call `Fetcher.youtubeTranscript({ url: "file:///etc/passwd" })` (also `ftp://`, `rtmp://`); assert `isError === true` with the "disallowed protocol" message. Spy on `child_process.execFileSync` with `hasYtDlp = true` and assert it is **never** invoked for non-http(s) URLs. No network or binary needed. | Yes |
| 3 | Redirect SSRF detect-only (Critical) | Three tiers: (a) keep the existing mocked-fetch redirect tests (final-URL revalidation) as a regression net. (b) New: unit-test the per-hop validator/dispatcher in isolation — feed it a synthetic redirect chain `public → private` and assert it aborts *before* connecting to the private hop, without any real sockets. (c) End-to-end: real 302 from a public host to a private target. | (a), (b) yes. **(c) NO — needs a reachable public host** |
| 4 | yt-dlp arg injection via `lang` (High) | (a) Unit: the (tightened) `lang` pattern rejects `-o`, `--sub-format`, `--skip-download`, leading-hyphen values, and overlong strings; accepts `en`, `es-419`, `zh-Hans`. Test at both call sites. (b) Integration: `hasYtDlp = true`, stub `execFileSync`, pass a malicious `lang`; assert the argv handed to yt-dlp contains no element equal to a registered flag. (c) Behavioral proof against the *real* yt-dlp parser. | (a), (b) yes. **(c) NO — requires the yt-dlp binary (pip install needs network; not present here)** |
| 5 | yt-dlp Unix-only, silent failure (High) | (a) Unit: workspace helper returns a path under `os.tmpdir()`; spy on `execSync` and assert no `mktemp`/`which` spawns. (b) Diagnostic: `hasYtDlp = true`, make the yt-dlp call throw; assert a fallback diagnostic is emitted (capture stderr) rather than silent. (c) Real behavior on a Windows host. | (a), (b) yes. **(c) NO — this is a Linux environment** |
| 6 | `extractPlayerResponse` `};` truncation (Medium) | Pure-function tests: player-response JSON whose string values contain `};` (embedded code, descriptions) must extract and `JSON.parse` fully; also a regression case for the current simple `= {...};` shape. | Yes |
| 7 | `parseTranscriptXml` fragility (Medium) | Pure-function tests: srv3 XML with non-first attribute order (`<p d=".." t="..">`); entity decoding for `&apos;`, `&nbsp;`, numeric `&#x27;`/`&#..;`; XML with zero recognizable captions must yield an error result, not success-with-empty. | Yes |
| 8 | Caption URL string concat (Medium) | Pure-function tests over `track.baseUrl` shapes: no `?` at all (must produce `?fmt=srv1`), has `?` and no `fmt`, has a *different* parameter whose value contains `fmt=` (must still append the real param). | Yes |
| 9 | `json()` round-trip mutation (Low) | Mocked fetch returning `9007199254740993` and `1e308`; assert whatever policy the fix adopts (passthrough vs. documented loss). The current code silently corrupts — the test pins the chosen contract. | Yes |
| 10 | Surrogate-pair splitting (Low) | Pure-function test: text containing emoji, with `max_length`/`start_index` boundaries landing inside a surrogate pair; assert output contains no lone surrogates (`/\ud800[\u0000-\uffff]/`-style check). | Yes |
| 11 | `hasYtDlp` stale cache (Low) | Stub the detection command to fail, then succeed; with fake timers (or an injectable TTL) advance time and assert a re-check happens and the new state is used. | Yes |
| 12 | JSDOM must stay script-free (Note) | Guard test: HTML containing `<script>window.__pwned = true</script>` driven through `Fetcher.txt` / `readable`; assert no side effect occurred. Fails the moment anyone adds `runScripts`. | Yes |

## Hard or impossible offline

1. **Finding #3, tier (c) — end-to-end redirect chain.** A real 302 from a *public* host to a private target requires an externally reachable server (or at minimum external DNS + internet egress). Fallback: the dispatcher-level unit test (tier b) covers the new validation logic in isolation; the existing mocked-fetch tests keep covering the detect-after-the-fact path. Only the full real-socket loop is deferred to an environment with network access.
2. **Finding #4, tier (c) — real yt-dlp parser behavior.** Proving the argparse reinterpretation requires the yt-dlp binary, which isn't installed and can't be installed offline (pip needs PyPI, or a pre-downloaded wheel). Fallback: argv-level assertions (tier b) plus the tightened regex (tier a) — the fix removes the attack surface regardless of parser behavior.
3. **Finding #5, tier (c) — Windows.** `mktemp`/`which` vs. `os.tmpdir()` portability can only be truly verified on a Windows host; not possible from this Linux environment. Fallback: assert the code no longer *spawns* those Unix commands (spy test), which is the actual defect.
4. **Conditional caveat on #1, tier (b):** if the isolated environment blocks even loopback sockets, the integration tier degrades to the unit tier (a), which still directly reproduces and verifies the bypass at the validation boundary.

**Net:** 10 of 12 findings are fully evaluable offline; #3 and #4 get strong component-level coverage offline with only their real-world end-to-end legs deferred; #5's Windows leg is the one truly untestable item here.
